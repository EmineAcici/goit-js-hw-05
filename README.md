# GoIT JavaScript Homework 05 - Gelişmiş Dizi Yöntemleri

Bu proje, GoIT Full Stack Developer eğitimi JavaScript modülünün beşinci ödevidir. Bu çalışmada; fonksiyonel programlama prensipleri, ok fonksiyonları (arrow functions) ve modern dizi metotları (map, filter, reduce, toSorted vb.) kullanılarak veri manipülasyonu üzerine uzmanlaşılmıştır.
